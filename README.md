# 🍽️ TasteBite – Modern Recipe Discovery App

A clean, responsive, and user‑friendly recipe exploration app built using **React**, offering category‑based browsing, detailed recipe information, and effortless bookmarking.

TasteBite helps users discover delicious recipes from multiple categories with an elegant UI, fast performance, and a smooth experience. Designed with a focus on simplicity and modern web standards, it’s perfect for food lovers and home cooks looking for cooking inspiration.

## 📘 About
TasteBite allows users to:

- 🔍 Browse recipes by category (Breakfast, Dessert, Vegetarian, etc.)
- 🍲 View full recipe details such as ingredients and instructions
- ⭐ Bookmark recipes using local storage
- 📱 Enjoy a clean, fast, mobile‑friendly UI

Built to deliver smooth navigation, quick data fetching, and an intuitive user experience.

---

## 💻 Tech Stack
- React  
- React Router  
- Tailwind CSS (or modern CSS)  
- Fetch API / Axios (depending on your implementation)  
- Local Storage for bookmarking

## 🛠️ Installation & Setup
Clone the repository:

```bash
git clone https://github.com/hardikdevaliya2006/Taste-Bite.git
cd Taste-Bite
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open in browser:  
Navigate to the URL shown in the terminal (usually http://localhost:5173).

## 📡 API Reference
